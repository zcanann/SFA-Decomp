# MusyX group-stack ownership

The EN `dataInitStack` function at `8027B420` consists only of a halfword
zero store to `sp` at `803DE308` and a return. It immediately precedes the
sound-group helpers and was previously assigned to the end of
`synth_vsamples.c`. The virtual-sample functions do not access `sp`;
`sndPushGroup` and `seqPlaySong` use it as the loaded-group count indexing
`gs[128]`.

[AxioDL MusyX s_data.c](https://github.com/AxioDL/musyx/blob/main/src/musyx/runtime/s_data.c)
corroborates a private signed-halfword stack counter and an initial
`dataInitStack` reset in the sound-group implementation for the older library
versions. This is library-lineage evidence, not recovered SFA source.

Move the reset and its declaration into `snd_groups.c` and its canonical
header. Define `static s16 sp` there. The compiler emits two bytes in an
eight-byte-aligned `.sbss` section; ordinary link alignment accounts for the
remaining six bytes before the next allocation. Correct the configured symbol
size from eight bytes to two and assign `803DE308..803DE310` to that unit.
No padding object or section override is needed.

The text boundary moves back twelve bytes to `8027B420`; outer boundaries,
exception tables, existing data, and every function body remain unchanged.
Both units retain 100% matches. Eight formerly autogenerated data bytes become
matched and linked C data (two bytes of storage plus alignment). This does
not add a newly matched function: the reset was already exact.

Validation: strict matching checksum and `ninja all_source`, each with a
30-second timeout; full DOL byte equality; object-level function comparison;
and a separate formatting pass checked for unchanged generated objects.
